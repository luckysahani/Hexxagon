# Hexxagon

The hexagonal board game, written in Python with pygame as my first-semester project at IIT Kanpur (July–October 2012). Play against another person, or against the computer at an easy or a hard level.

## Run it

The game is written for **Python 2** and pygame.

```sh
pip install pygame          # in a Python 2.7 environment
cd Projectfinal.py
python Projectfinal.py
```

## What is where

- `Projectfinal.py/` — the finished game: `Projectfinal.py` and the images it loads.
- `Project4/` — the working versions on the way there (`a65.py` … `a75.py`).
- `Projectfinal.py.zip`, `Project4.zip` — archives of the two folders.
